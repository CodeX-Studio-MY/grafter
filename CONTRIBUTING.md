# Contributing

Grafter is pre-alpha and in a private pilot. Contributions open with the public release (roadmap phase 5).

- Python 3.12+, `pip install -e ".[dev]"`, `ruff check .`, `pytest`.
- One change per PR.
- Code copied from other projects: MIT/Apache only, keep its licence notice, add it to `THIRD_PARTY.md`. No GPL/AGPL.
- Never commit real client code, names or data. Use the fictional `examples/`.
