# Landscape and prior art

GitHub Next calls this space **Continuous AI**. Grafter's difference: charter-bound, 1:1, multi-repo, preview-branch model with an audit trail.

| Who | Type | Notes |
|---|---|---|
| [GitHub Next — Continuous AI](https://githubnext.com/projects/continuous-ai/) | Concept + Agentic Workflows preview | Read-only by default; writes need approval |
| [Google Jules](https://jules.google/docs/suggested-tasks/) | Commercial | Suggested + scheduled tasks |
| [Ona Automations](https://ona.com/stories/ona-automations-proactive-background-agents) | Commercial | Scheduled background agents |
| [Kai (Dria)](https://kai.dria.co/blog/codebases-that-improve-themselves) | Commercial | "Codebases that improve themselves" |
| Charlie Labs Daemons | Commercial | Self-initiated maintenance tasks |
| [OpenBot](https://github.com/YiAgent/openbot) | Open source | Self-hosted maintenance bot (Python, Redis, sandbox) |
| Octomus | Self-hosted preview | Finds repo work before coding |
| [OpenHands](https://github.com/OpenHands/software-agent-sdk) | Open source (MIT) | Agent SDK — Grafter's default engine |
| [Darwin Gödel Machine](https://github.com/jennyzzt/dgm) | Research | Self-improving coding agents |

## Reuse rules

- MIT/Apache code may be copied with its copyright and licence notice kept; list it in [THIRD_PARTY.md](../THIRD_PARTY.md).
- No GPL/AGPL code. No code from repos without a licence.
- Ideas and architecture may be borrowed; credit inspirations openly.
